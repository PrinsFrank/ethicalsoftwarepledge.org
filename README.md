# EthicalSoftwarePledge.org

This repository contains the source for [ethicalsoftwarepledge.org](https://ethicalsoftwarepledge.org), 
the [Pledge itself](PLEDGE.md), and a list of organizations and developers that signed the pledge.

To sign this pledge as an organization, add your organizations' details in _data/organizations.yml using a PR to this repo.
To sign this pledge as an developer, add your details in _data/developers.yml using a PR to this repo.
